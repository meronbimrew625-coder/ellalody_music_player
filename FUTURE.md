# Future Improvements

1. Replace browser-only demo sign-in/sign-up with server-side authentication and a database.
2. Add server-verified authorization before any protected write or private-data access.
3. Add user-specific persistence for favorites, playlists, and listening statistics.
4. Add clear caching and revalidation for public catalog data, with private user data isolated from shared caches.
5. Improve accessibility and record measured Lighthouse/performance results.
6. Consider a native mobile/desktop app if the product must manage or hide original media files from the operating system's Gallery or File Explorer. A web app cannot hide or delete the original files from those apps.
7. Add automated tests for route behavior, quiz scoring, storage helpers, and error states.
